# חוברת התרגילים בהסתברות לסטטיסטיקה (214.1.9921)

אתר התרגול של הקורס, סמסטר א׳ תשפ״ז: https://motkep173.github.io/Ex2027A_9921/

- `index.html`: האתר, עם פתרונות שנפתחים שלב אחר שלב.
- `booklet.pdf`: חוברת התרגילים.
- `solutions.pdf`: חוברת הפתרונות.

ה-repo הזה הוא גם המקור של החוברת והאתר: כל השאלות נמצאות כאן כקובצי LaTeX, וממנן נבנים שלושת הקבצים. GitHub Pages מפרסם את הענף `main`, תיקיית השורש, ולכן כל מיזוג ל-`main` מתפרסם לסטודנטים.

## מה לא נמצא כאן

ה-repo ציבורי. הדברים האלה נשארים ב-repo הפרטי של הקורס, `lectureNotes9921`, בתיקייה `exercises/`:
- **המקור של כל שאלה** (דף, סמסטר, קובץ) והערות פנימיות: `exercises/metadata.md`.
- **שאלות מוצעות** שעוד לא אושרו (בתיבה ורודה): `exercises/suggested/`.
- **הערות הבדיקה** (`REVIEW.md`) ו**קבצי המקור** (`sources/`).

לכן בכותרת של קובץ שאלה אין שדות `source`, `file` או `note`, ובגוף הקובץ אין הערות שמציינות מקור.

## עדכון החוברת והאתר

**אוטומטית:** GitHub Action (`.github/workflows/build.yml`) בונה את החוברות ואת האתר בכל PR ובכל מיזוג ל-`main`. ב-PR הוא רק בודק שהכול נבנה, וה-PDF-ים מצורפים להרצה (Actions ← ההרצה ← Artifacts). אחרי מיזוג ל-`main` הוא מבצע commit של `index.html`, `booklet.pdf`, `solutions.pdf` וקובצי ה-tex שנוצרו, ו-GitHub Pages מפרסם אותם. מספיק לשנות את קובצי השאלות.

**ידנית**, למשל כדי לראות את התוצאה לפני push:

```
python3 make_bank.py
python3 make_site.py            # בונה את index.html
python3 make_site.py --check    # וגם בודק כל נוסחה ב-MathJax (פעם ראשונה: cd site && npm install)
xelatex booklet.tex && xelatex booklet.tex
xelatex solutions.tex && xelatex solutions.tex
```

מקמפלים ב-**XeLaTeX**. הקומפילציה השנייה נדרשת בשביל תוכן העניינים. את `tcolorbox` צריך לטעון *לפני* `MotkePreamble`, כמו בתבנית. אחרת גרסאות חדשות של `bidi` עוצרות את הקומפילציה בשגיאה על `listings`.

## מבנה של קובץ שאלה

```latex
% ==================================================================
% id:       rv-003
% topic:    משתנים מקריים
% subtopic: משתנים מקריים מוכרים
% solution: full            (full / partial / none)
% ==================================================================
שנה אחרי שנה, פרופסור אקס מלמד את הקורס ...
\begin{enumerate}
\item ...
\begin{solbox} ... \end{solbox}
\end{enumerate}
```

הקובץ **לא** מתחיל ב-`\item`, ולכן בדף התרגילים כותבים `\item \input{...}`.

## הוספת שאלה חדשה

1. יוצרים קובץ בתיקיית הנושא עם המזהה הפנוי הבא, למשל `rv-009.tex`, וממלאים את הכותרת. אם זה תת־נושא חדש, מוסיפים אותו גם ל-`structure.txt`. המזהה צריך להיות פנוי גם בין השאלות המוצעות ב-repo הפרטי.
2. את המקור של השאלה רושמים ב-`exercises/metadata.md` ב-repo הפרטי, לא בקובץ.
3. מריצים את הפקודות שבסעיף "עדכון החוברת והאתר". `make_bank.py` בודק שאין מזהים כפולים.

## הנושאים והסדר

הפרקים, ותתי־הנושאים בכל פרק, מסודרים לפי `structure.txt`. כדי לשנות את הסדר מזיזים שורות בקובץ ומריצים `make_bank.py`. בתוך תת־נושא, השאלות מסודרות לפי המזהה. מספור השאלות בחוברת רץ ברצף מהשאלה הראשונה עד האחרונה.

התיקייה והמזהה של שאלה לא קובעים את המיקום שלה. כלומר שאלה מהתיקייה `05-random-variables` יכולה להופיע בפרק אחר, לפי תת־הנושא שלה.

## החוברות

בחוברות אין כותרות של תתי־נושאים, אין מזהים ואין מקורות. את הסמסטר ואת ההערה בעמוד השער עורכים ב-`booklet-header.tex`. שם מוגדר גם העיצוב: הצבעים, כותרות הפרקים וההפרדה בין התרגילים (`\bookletstyle`: `lines`, `boxes` או `space`). בעמוד השער יש קישור לאתר וקוד QR (`\siteurl`). תאריך "עודכן לאחרונה" מתעדכן לבד בכל קומפילציה. תרגיל לא נשבר בין עמודים.

## האתר

`index.html` הוא אתר בעברית: מפה של נושאים ותתי־נושאים, סינון, ופתרון שנפתח שלב אחר שלב. כל תרגיל מופיע עם המספר שלו בחוברת, והפניה לשאלה אחרת (`\qref`) מוצגת כמספר התרגיל בחוברת.
- שאלה שלכל אחד מהסעיפים שלה יש `solbox` משלו מתפצלת לכרטיס לכל סעיף, והפתיחה המשותפת חוזרת בכל כרטיס. `solbox` שבא לפני רשימת הסעיפים מוצג בתחילת הפתרון של כל סעיף.
- הפתרון מתחלק לשלבים: כל פסקה, כל `\item` ברשימה שבפתרון, וטקסט שבא אחרי נוסחה במרכז השורה.
- מאקרו חדש שמשתמשים בו בנוסחאות צריך להוסיף ל-`site/macros.json`. `--check` מודיע אם חסר מאקרו.

## דיאגרמות ון וטבלאות

- **דיאגרמת ון** לשלוש קבוצות: `\venn{1/1/0,0/1/1}{(ג)}`. כל שלישייה היא אזור צבוע (1 = בתוך הקבוצה, 0 = מחוצה לה, לפי הסדר A/B/C), והארגומנט השני הוא הכיתוב. בחוברות היא מצוירת ב-TikZ, ובאתר `make_site.py` מצייר אותה ב-SVG.
- **טבלה** (`tabular`): באתר היא הופכת לטבלת HTML. שורות שמעל ה-`\hline` הראשון הן שורות כותרת, ו-`|` במפרט העמודות מצייר קו.
- הפקודות של הקורס (`\PP`, `\E`, `\Var`, `\Bin`, `\Poi`, `\Geo`, `\Ber`, `\set`, `\comp`, `\ans` ועוד) מוגדרות ב-`bank-setup.tex` לחוברות וב-`site/macros.json` לאתר.

## רמזים

עדיין אין רמזים בחוברת. כל עוד אין אף רמז, החוברות והאתר מדברים רק על פתרונות. לכל סעיף אפשר להוסיף רמז בשורה נפרדת, לפני ה-`solbox` שלו: `\hint{...}`. אם השאלה כולה היא כרטיס אחד באתר, הרמז נכתב לפני ה-`solbox` הראשון שלה. בחוברת התרגילים הרמז מוסתר, בחוברת הפתרונות הוא מופיע ברשימת הרמזים, ובאתר הוא נפתח בכפתור „קבלת רמז”.

## פתרונות שטרם נבדקו

פתרון שעוד לא נבדק מסומן ב-`\unverified` בשורה הראשונה של ה-`solbox` וב-`% verified: no` בכותרת. באתר ובחוברת הפתרונות הוא מסומן "פתרון שלא נבדק על ידי צוות הקורס", וב-`catalog.md` ב-⚠️. אחרי בדיקה מוחקים את שתי השורות ובונים מחדש.

## שאלות מוצעות

השאלות המוצעות נמצאות ב-repo הפרטי (`exercises/suggested/`), באותו מבנה תיקיות כמו `questions/`. כדי לראות אותן יחד עם המאגר, משכפלים את שני ה-repos זה לצד זה ומריצים:

```
python3 make_site.py --with-suggested ../lectureNotes9921/exercises/suggested   # preview.html
python3 make_bank.py --with-suggested ../lectureNotes9921/exercises/suggested    # bank-preview.tex
```

שני הקבצים לא נשמרים ב-git, ושום קובץ אחר לא משתנה.

כדי לאשר שאלה: מעבירים את הקובץ מ-`exercises/suggested/<נושא>/` ב-repo הפרטי ל-`questions/<נושא>/` כאן. מוחקים ממנו את `\begin{suggested}`, `\end{suggested}` ו-`% suggested: yes`, ומעבירים את שדות ה-`source`/`file`/`note` שלו ל-`exercises/metadata.md`. אחרי בדיקת הפתרונות מוחקים גם את `\unverified` ואת `% verified: no`. אחר כך בונים מחדש.

## הרכבת דף תרגילים

1. בוחרים שאלות ב-`catalog.md`.
2. מעתיקים את `sheet-template.tex` ומוסיפים שורה לכל שאלה: `\item \input{questions/05-random-variables/rv-003}`.
3. מקמפלים ב-XeLaTeX: עם `\solfalse` יוצא דף לסטודנטים, ועם `\soltrue` דף פתרונות.

## מוסכמות עיצוב בקובצי השאלות

- **הוראה מודגשת:** בשאלה עם הוראה וסעיפים, ההוראה כתובה ב-`\textbf{...}`.
- **שתי עמודות:** כשכל הסעיפים קצרים, הרשימה עטופה ב-`\bMs{2} ... \eMs`. העמודות מופיעות רק בגרסה בלי פתרונות.
- **סוגריים בטקסט עברי:** כותבים אותם רגיל, `(...)`.
- **משלים:** `A^C`, כמו בסיכומי ההרצאות (לא `\comp{A}` או `\overline{A}`). למשלים של ביטוי כותבים סוגריים: `(A\cup B)^C`.
- **הפניות בין שאלות:** `\qref{comb-002}`. במאגר מודפס המזהה, ובחוברות ובאתר מספר התרגיל.
